Nhật ký công việc ghi lại toàn bộ lộ trình thực tập và học tập trong **12 tuần** tại chương trình **First Cloud AI Journey (FCAJ) 2026**. Lộ trình được chia thành hai giai đoạn chính:

- **Giai đoạn 1 (Tuần 1 – Tuần 8):** Tiếp cận nền tảng điện toán đám mây AWS, tìm hiểu và thực hành các dịch vụ hạ tầng trọng tâm bao gồm Networking (VPC), Security (IAM), Compute (EC2), Storage (S3, EBS), Database (RDS), Serverless (Lambda, API Gateway), Monitoring (CloudWatch, SNS), High Availability & Scalability (ELB, Auto Scaling) và Quản trị qua AWS CLI.
- **Giai đoạn 2 (Tuần 9 – Tuần 12):** Thực hiện dự án capstone **NutriVision** – Hệ thống nhận diện món ăn và ước tính giá trị dinh dưỡng tự động từ hình ảnh, ứng dụng mô hình Deep Learning (EfficientNet-B0) triển khai trên kiến trúc AWS Serverless (Lambda Container, API Gateway, S3, Rekognition, CloudWatch, SNS và Amplify Hosting).
